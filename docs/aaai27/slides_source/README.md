# Talk slides: source copy

The live deck is the claude.ai artifact https://claude.ai/artifact/2MdTNDZVzu45zMuGJvWKpU, which is private to its owner
until shared. The deck can be downloaded as PowerPoint or PDF from the artifact page.

This folder is a backup copy of its source files: `project/deck.json`, `project/deck.css` and `project/slides/*.html`,
each with speaker notes in its `<aside>`. The chart on the "generated" slide is `docs/aaai27/figures/fig4_diagnoses.png`,
uploaded to the artifact as an asset. The text follows `docs/aaai27/talk_outline.md`; every number comes from the
PROJECT_NOTES items each slide cites.
