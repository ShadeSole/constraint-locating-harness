Three pairs fit. Covering finds the failure, not the cause. A locating suite adds tests until only one fits.

Forbidden combinations can make some causes impossible to tell apart (Jin & Tsuchiya 2020).

Configurable software, like compilers, web servers and ML training pipelines, often fails only when particular settings meet. Standard combinatorial testing makes sure every pair of settings gets tested, so you’ll see the failure. But a failing test doesn’t tell you which combination caused it: here test 1 fails, and three different pairs could explain it. Locating arrays are test suites designed so that the pattern of passing and failing tests points to the cause. Real systems also forbid some combinations, and that can make two causes impossible to tell apart. (About 45 seconds.)
